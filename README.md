# 米公小学教学质量分析跟踪系统

## 📖 项目简介

为米公小学开发的一套网页版教学质量分析跟踪系统，用于管理6个年级×5个班级的成绩数据，支持横向对比和纵向跟踪。

## 🛠 技术栈

- **前端框架**：React 18 + Vite 5
- **UI组件库**：Ant Design 5
- **数据库**：Supabase (PostgreSQL)
- **图表**：ECharts 5 + echarts-for-react
- **导出功能**：xlsx.js (Excel)、jsPDF (PDF)
- **样式**：原生CSS

## ✨ 功能特性

### 1. 数据管理
- ✅ 6个年级 × 5个班级 × 多学科成绩管理
- ✅ 21个固定字段（学年度、学期、学科、年级、班级、任课教师、应考人数、实考人数、高分人数、及格人数、低分人数、人平分、高分率、及格率、低分率、人平分率、综合指数、年级平均综合指数、与年级第一对比差值、上学期综合指数、净升率）
- ✅ Excel批量导入/导出
- ✅ 单条数据新增/编辑/删除
- ✅ 多条件筛选查询

### 2. 计算公式（严格按需求执行）
- 高分率 = 高分人数 ÷ 实考人数 × 100% → 保留2位小数
- 及格率 = 及格人数 ÷ 实考人数 × 100% → 保留2位小数
- 低分率 = 低分人数 ÷ 实考人数 × 100% → 保留2位小数
- 人平分率 = 人平分 ÷ 100 × 100% → 保留2位小数
- 综合指数 = (高分率 + 及格率 + 人平分率 − 低分率) ÷ 3 → 保留4位小数
- 年级平均综合指数 = 同年级、同学科所有班级综合指数的平均值 → 保留4位小数
- 与年级第一对比差值 = 本班综合指数 − 同年级同学科第一名综合指数 → 保留4位小数
- 净升率 = 本期综合指数 − 上学期综合指数 → 保留4位小数

### 3. 异常数据提醒
- ✅ 实考人数 > 应考人数
- ✅ 率值超出 0-100%
- ✅ 学年度/学期格式错误

### 4. 横向对比
- ✅ 班级综合指数 vs 年级平均/第一名
- ✅ 同年级同学科各班对比
- ✅ 同一班级各学科强弱对比
- ✅ 柱状图、雷达图等多维展示

### 5. 纵向跟踪
- ✅ 以「届次+班级编号」串联六年数据
- ✅ 班级历年综合指数趋势图
- ✅ 教师历年教学成绩跟踪
- ✅ 任意两学期跨期对比

### 6. 可视化图表
- ✅ 班级多年成绩折线图
- ✅ 教师历年教学成绩折线图
- ✅ 同学期班级横向对比柱状图
- ✅ 班级多学科雷达图
- ✅ 支持图表导出（图片/Excel/PDF）

### 7. 智能分析报告
- ✅ 班级单学期/跨学年成绩分析
- ✅ 教师教学效果分析
- ✅ 年级/学校整体质量分析
- ✅ 教学建议（提优、补差、偏科改进）
- ✅ 导出：Excel数据报表、PDF质量分析报告

### 8. 权限设置
- ✅ 管理员：查看/修改/删除全校所有数据，管理学期目录
- ✅ 普通教师：仅查看/导入自己所带班级数据

## 🚀 快速开始

### 环境要求
- Node.js >= 16.0
- npm 或 yarn
- Supabase 账户

### 1. 克隆项目
```bash
git clone <repository-url>
cd 教学质量分析系统
```

### 2. 安装依赖
```bash
npm install
```

### 3. 配置 Supabase

在 Supabase 后台创建项目后：

1. 获取项目 URL 和 anon key
2. 创建 `.env` 文件：
```bash
VITE_SUPABASE_URL=your-supabase-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

3. 在 Supabase SQL Editor 中运行 `supabase/schema.sql` 脚本

### 4. 启动开发服务器
```bash
npm run dev
```

访问 http://localhost:3000

## 🎯 使用流程

### 1. 管理员初始化
1. 登录系统（使用管理员账号）
2. 进入「系统设置」→「学期管理」，创建当前学年度学期
3. 进入「用户管理」，添加教师账号

### 2. 数据导入
1. 进入「数据管理」
2. 选择学年度和学期
3. 点击「导入Excel」，选择已准备好的Excel文件
4. 预览数据，确认无误后点击「确认导入」

### 3. 数据分析
1. 首页查看整体概况
2. 进入「横向对比」分析班级差异
3. 进入「纵向跟踪」查看历年变化
4. 进入「可视化图表」生成多维图表
5. 进入「智能分析报告」生成分析报告

## 📊 Excel导入模板

Excel文件应包含以下列（顺序不可调整）：

| 学年度 | 学期 | 学科 | 年级 | 班级 | 任课教师 | 应考人数 | 实考人数 | 高分人数 | 及格人数 | 低分人数 | 人平分 |
|--------|------|------|------|------|----------|----------|----------|----------|----------|----------|--------|
| 2024-2025 | 上学期 | 语文 | 1 | 1 | 张老师 | 45 | 45 | 20 | 40 | 2 | 85.5 |

## 🔧 部署到 Vercel（免费）

### 方法一：使用 Vercel CLI

```bash
# 安装 Vercel CLI
npm i -g vercel

# 登录
vercel login

# 部署
vercel

# 生产环境部署
vercel --prod
```

### 方法二：使用 GitHub 集成

1. 将项目推送到 GitHub 仓库
2. 访问 https://vercel.com/new
3. 导入 GitHub 仓库
4. 配置环境变量：
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
5. 点击 Deploy

### 环境变量配置

在 Vercel 项目设置中添加：

```
VITE_SUPABASE_URL = your-supabase-url
VITE_SUPABASE_ANON_KEY = your-supabase-anon-key
```
