# 米公小学教学质量分析系统

## 使用说明

### 1. 解压代码
下载 `teaching-quality-system-v2.tar.gz`，解压到本地

### 2. 安装依赖
```bash
npm install
```

### 3. 本地运行
```bash
npm run dev
```
访问 http://localhost:5173

### 4. 部署到 Vercel
1. 把整个文件夹上传到 GitHub 新仓库
2. 打开 https://vercel.com/new
3. 导入你的 GitHub 仓库
4. 点击 Deploy

### 登录账号
- 用户名：admin
- 密码：admin123

## 功能模块
- 数据录入：单条录入，自动计算综合指数
- Excel导入：批量导入数据，支持模板下载
- 横向对比：班级vs年级对比，柱状图、雷达图
- 纵向跟踪：历年成绩趋势，教师教学跟踪
- 可视化图表：多维度数据分析

## 计算公式
- 高分率 = 高分人数 / 实考人数 * 100%
- 及格率 = 及格人数 / 实考人数 * 100%
- 综合指数 = (高分率 + 及格率 + 人平分率 - 低分率) / 3
